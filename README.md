# Minimal Study Timer

A simple, customizable Pomodoro timer made for focus.

I made this because I couldn't find a timer that was minimal and customizable without being flashy, confusing, or needing an app download. The black-and-white design helps keep distractions low.

The little sunflower is a personal touch, my wife loves sunflowers. 🌻

## Features

- Focus and short-break sessions
- Optional long breaks
- Customizable session lengths
- Auto-start breaks
- Fullscreen mode

## Use it

Open `MinimalStudyTimer.html` in your browser.

Made for myself, but hopefully useful for other students too.
